# Roadmap

## 0.4

- Typed, persistent CEFR profiles with fixed/adaptive modes
- Range-aware cards and structured model policy
- Declarative content/pet packs, shared validator, examples, schemas and CI

## Later

- Community pack signing and trust UI
- More built-in languages and accessibility QA
- Further extraction of persistence, content, model, pet, scheduler, and UI targets

Runtime provider plugins, arbitrary Swift/plugin execution, automatic Developer ID setup, and cloud memory are intentionally unsupported.
